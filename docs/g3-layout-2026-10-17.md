# G3: layout at every list size, 2026-10-17

Singleplayer test world, build 34c95ad (0.5.0-rc1), Monitoring Stand open,
Production Limits panel (Alt+F1), windowed 16:9. Screenshots (zooms of the game
window) in [test-results/g3-20261017/](../test-results/g3-20261017/) (local,
not in git).

## How the list sizes were made

New legacy rules cannot be created in 0.5, so the user's two guild rules were
removed for the test (0 entries) and the other sizes came from temporary
`work_caps` in the installed config.lua with ceiling 9999999 (never met, so no
work stopped), applied with `!pwp reload`. Generator: a scratch script writing
1, 13, 14, 26 or 27 (work, item) pairs. Afterwards the two guild rules were
re-added through the config.lua detour (see g4-scheduling-2026-10-17-miners.md)
and config.lua restored byte for byte; rules and priorities diff equal to the
snapshots, `!pwp limit` shows Wood 47799 / 30000 and Stone 44900 / 35000.
