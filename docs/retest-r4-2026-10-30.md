## Merge

Seven fix branches from c563374 were merged into `integrate-r4`: sched, stand, net,
persist, docs, panel and tooling. The only conflict was in
`tests/test_main_integration.lua`, where both sides had added tests, so both blocks were kept.
The docs agent's new INSTALL.txt wording went to the tooling agent and is built by
`release.py`.

Three fixes came out of the retest itself:

- **All ore ids count as rock drops** (cb2ef85). The panel agent's rock list missed
  manganese, sky island and world tree ore and meteorite drops. All of them are in the
  game's item list (`icondex.lua`) and would have said "Cannot be limited". Soralite showed
  "Add item limit" in game after the fix.
- **A Sandwich is cooked, not mined** (a0b418c). `"sand"` sent it to Mining, so in v0.5.0
  a Sandwich limit would have counted against Mining. Seen in the picker as "Cannot be
  limited". A scan of every item id in `icondex.lua` that lands on Mining found no other
  real product. The rest (Forest helmet and spear, Rainbow Crystal, whale whistle
  fragments, NightStone, Pal_crystal_L) are made by no base, so "Cannot be limited" is
  right for them.
- **The stand keeps saying the mod is paused** while `config.lua` is rejected (598ea8d).
  It showed the reason once for 12 s and then the normal legend.

Tests on 598ea8d: 252 Lua scripts with 0 failures, and luacheck is clean apart from the
known 193-locals note. 832 Python tests pass, 85 skipped. The change note is 7,978 bytes.

## Regression review of the fixes (round 5)

The user asked that every change be tested in game and that the fix agents' work be
checked strictly: "no new bugs, only the old ones gone, and no performance hit". Six
reviewers then checked only the diff c563374..907a5eb.

| Reviewer | Score | Worst finding in the fixes |
| --- | --- | --- |
| Scheduler | 5 | **P1:** a Pal with one numbered job was steered, so the staffing maximum switched off a Chikipi's only job. The fix agent had **edited an existing test** to fit the change. |
| Engine safety | 7 | **P2:** one failed save (antivirus or OneDrive lock) turned the whole stand into "?" and stopped editing. Two agents had built the same check twice, and the copy in use was wrong. |
| Persistence | 7 | **P2:** a cut-off `priorities.txt` could still replace the good `.bak`. The round-4 fix had only changed the warning. |
| Multiplayer | 7 | **P2:** a re-made peer's count stream restarted at 1, so counts were refused for about 50 s. The fix was half done. |
| Panel | 8 | P3 only |
| Performance | 8 | P3 only. Its "legend test missing" was wrong: the test is at `tests/test_ui_integration.lua:1760`. |

Found in game during this pass (not by a reviewer): while a save was being retried, a
click said "That change was not made", although the edit was kept and saved 2 s later.
That text was new in round 4.

**Fixes.** I fixed the P1, the engine P2, that message, the scheduler P3s (a work is
remembered as ignored only for stations that never take a Pal; Chromite and meteorite
rocks count as Mining), one source for the store refusal, and the stand wording. Three
fix agents with separate files did the rest, under a stricter brief: no existing
assertion weakened, every new test fails without its fix, and every caller checked.
- **persist:** an unverified live file never replaces `.bak`; a `.bak` with a byte order
  mark reads; a failed first migration is not called a removed `config.lua`.
- **net:** the count stream starts new peers at the server's count; a delta needs a full
  table first; a locked client keeps its reason through the retry, which now waits up to
  60 s; a rejoin needs 3 missed counts; the no-answer text is true for silent modded
  servers too.
- **panel:**
  - the keys release the highlight without a hover map;
  - a new search starts on page 1 with no stale frame;
  - a second Escape closes even if the search box kept the keyboard;
  - honest Remove-cancel and search-disarm notices;
  - an old Mining limit on Sandwich opens as Edit;
  - a Leather/Horn/Bone limit says it stops its whole job.

I read every agent diff before merging. Changed existing assertions: the net agent
changed six, each pinning a behaviour or text a finding changes; the other agents
changed none.
