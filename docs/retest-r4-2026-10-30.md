## Merge

Seven fix branches from c563374 were merged into `integrate-r4`: sched, stand, net,
persist, docs, panel and tooling. The only conflict was in
`tests/test_main_integration.lua`, where both sides had added tests, so both blocks were kept.
The docs agent's new INSTALL.txt wording went to the tooling agent and is built by
`release.py`.

Three fixes came out of the retest itself:

- **All ore ids count as rock drops** (cb2ef85). The panel agent's rock list missed
  manganese, sky island and world tree ore and meteorite drops. All of them are in the
  game's item list (`icondex.lua`) and would have said "Cannot be limited". Soralite showed
  "Add item limit" in game after the fix.
- **A Sandwich is cooked, not mined** (a0b418c). `"sand"` sent it to Mining, so in v0.5.0
  a Sandwich limit would have counted against Mining. Seen in the picker as "Cannot be
  limited". A scan of every item id in `icondex.lua` that lands on Mining found no other
  real product. The rest (Forest helmet and spear, Rainbow Crystal, whale whistle
  fragments, NightStone, Pal_crystal_L) are made by no base, so "Cannot be limited" is
  right for them.
- **The stand keeps saying the mod is paused** while `config.lua` is rejected (598ea8d).
  It showed the reason once for 12 s and then the normal legend.

Tests on 598ea8d: 252 Lua scripts with 0 failures, and luacheck is clean apart from the
known 193-locals note. 832 Python tests pass, 85 skipped. The change note is 7,978 bytes.
