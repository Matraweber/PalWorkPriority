**Found and fixed here:** the rejection notice ran past the panel's right edge.
It is shorter now ("Fix it, or delete config.lua and restart. No Pals are assigned
until then."), and the README and INSTALL.txt say what `config.lua rejected` means
(7eeb1ca).

**Process slip:** the shortened `main.lua` was copied into the test install while
the game ran. The running game had already loaded its scripts, so nothing changed
until the next restart, but the rule is to copy only with the game closed.
