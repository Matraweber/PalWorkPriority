It is shorter now ("Fix it, or delete config.lua and restart. No Pals are assigned

the game ran. The running game had already loaded its scripts, so nothing changed
until the next restart, but the rule is to copy only with the game closed.

## Smaller findings from this retest

- **Options path.** The game menu (ESC) has a "Darn Mod Options" button. The round-3
  docs change to "ESC > Options > Mod Options" was wrong and is reverted in the
  README, CHANGELOG, store page draft and a code comment.
- **Selection after adding a limit.** The notice says "Left/Right now step it", but
  the selection stays on "Add a limit", not on the new row. Up reaches the row.
  Not fixed (P3).
- **Legend and the game's "unused Stat Points" bar** overlap at the bottom of the
  screen when both show (newcomer P3-8, now seen). Not fixed (P3).
- **The server macro's "--world" and "--stand" modes** stopped with "Normal exit did
  not finish" on both tries this evening; "--title" worked. Leaving the world was
  done by hand through the menu.
- An extra tile arm 2 s after opening the picker on the client was seen once and not
  reproduced; it most likely came from the focus helper's title-bar click.
